PersonalComputerDeskOrganizer

◆

Recréez en un clic vos bureaux virtuels Windows, leurs zones d'écran et les applications, fichiers et pages web qui doivent s'y ouvrir.

Télécharger pour Windows Version .zip

Installation

  1. Téléchargez PersonalComputerDeskOrganizer.exe (Windows 10 ou 11, 64 bits).
  2. Placez-le où vous voulez, par exemple dans Documents, puis double-cliquez dessus. Aucune installation ni droits administrateur requis.
  3. Dans ⚙ Réglages, activez le démarrage automatique si vous le souhaitez.
Avertissement Windows SmartScreen : l'application n'est pas signée numériquement. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Mise à jour

Téléchargez la nouvelle version et remplacez l'ancien fichier .exe. Vos profils sont conservés dans %AppData%\PersonalComputerDeskOrganizer.
